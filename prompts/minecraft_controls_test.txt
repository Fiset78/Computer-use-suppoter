[마인크래프트 조작 테스트]
마인크래프트 Java Edition 창이 열려 있고 크리에이티브 모드, 평지(Superflat), 치트 허용 월드에 들어가 있다.
목표: 아래 체크리스트의 조작을 하나씩 실제로 해 보고, 각 항목이 성공(O)인지 실패(X)인지 화면으로 확인해 기록한다.

== 단계 예산 규칙 (가장 중요) ==
- 이 프로그램은 응답 30번(단계 30)이 지나면 강제로 끝난다. 당신은 단계 번호를 따로 알 수 없으니 직접 센다.
- 모든 응답의 첫 줄에 [단계 N/30]을 쓴다. 첫 응답이 1이고, 응답할 때마다 1씩 올린다.
- 한 응답에 행동을 여러 개 묶어서 보내 단계를 아낀다. 묶음 끝에는 screenshot을 넣는다.
- 단계 24가 되었거나, 남은 항목을 단계 26 안에 끝낼 수 없다고 판단되면 즉시 아래 [인계 절차]를 실행한다.
- 체크리스트를 전부 끝냈으면 인계하지 말고 도구 호출 없이 최종 결과표만 보고하고 끝낸다.

== 시작할 때 ==
- 이 목표 맨 끝에 [이어서] 메모가 있으면, 메모의 결과는 다시 테스트하지 말고 메모가 가리키는 다음 항목부터 진행한다.
- 처음 화면에 PowerShell 창이 앞에 있으면 작업 표시줄의 마인크래프트 아이콘을 클릭해 게임 창으로 전환한다.
- 일시정지 메뉴가 떠 있으면 게임으로 돌아가기 버튼을 누르거나 Esc를 누른다.

== 조작 요령 ==
- 게임 안에서는 마우스 커서가 숨겨지고 화면 중앙에 고정된다. 시점 회전은 mouse_move로 화면 중앙에서 원하는 방향으로 떨어진 좌표로 옮긴다 (오른쪽으로 옮기면 오른쪽을 본다). 한 번에 조금씩 움직인다.
- 이동처럼 누르고 있어야 하는 키는 hold_key를 쓴다 (예: w를 1초). 동시에 누를 키는 ctrl+w처럼 묶는다.
- 결과 확인에는 F3 디버그 화면이 가장 정확하다. XYZ 좌표와 Facing(바라보는 방향)이 왼쪽 위에 나온다. 글자가 작으면 zoom으로 확대해서 읽는다. F3을 켜 둔 채로 이동/회전 테스트를 한다.
- 결과를 추측하지 않는다. 행동 전후의 화면이나 F3 수치가 달라졌는지 보고 판정한다.
- 한 항목을 두 번 시도해도 안 되면 X로 기록하고 이유를 짧게 적은 뒤 다음 항목으로 넘어간다.
- Alt+F4, 월드 삭제, 게임 종료, 설정 변경은 하지 않는다.

== 체크리스트 ==
1. 게임 창 포커스: Esc로 일시정지 메뉴 열기, 다시 Esc로 닫기
2. F3 디버그 화면 켜기, 좌표와 Facing 읽기
3. 시점 회전: 좌우 회전 (Facing 값 변화 확인), 위아래 보기
4. 이동: w 앞, s 뒤, a 왼쪽, d 오른쪽 각각 hold_key 1초 (좌표 변화 확인)
5. 점프: space 한 번, w+space로 이동 점프
6. 달리기: ctrl+w 2초 (같은 시간 걷기보다 더 멀리 가는지 좌표로 비교)
7. 웅크리기: shift 누른 채 이동 (shift+w), 캐릭터가 낮아지고 느려지는지
8. 비행: space를 빠르게 두 번 눌러 비행 켜기, space 상승, shift 하강, 다시 space 두 번으로 끄기
9. 핫바 선택: 숫자 1~9 키, 마우스 휠 위/아래로 선택 칸이 바뀌는지
10. 채팅: t로 채팅창 열기, hello 입력 후 Enter, 채팅에 표시되는지
11. 명령어: t 대신 / 키로 열고 gamemode survival 입력 후 Enter (서바이벌 전환 확인)
12. 블록 부수기 (꾹 누르기): 발밑 앞쪽 잔디 블록을 바라보고 left_mouse_down, wait 2초, left_mouse_up. 블록이 사라지고 아이템이 떨어지는지
13. 아이템 줍기: 떨어진 아이템 쪽으로 걸어가 핫바에 들어오는지
14. 블록 설치: 그 블록을 손에 든 채 바닥을 보고 right_click으로 설치
15. 손 바꾸기: f로 아이템을 왼손(보조 손)으로, 다시 f로 되돌리기
16. 아이템 버리기: q로 1개 버리기
17. 인벤토리: e로 열기, 아이템 하나를 클릭해 다른 칸으로 옮기기, e 또는 Esc로 닫기
18. 명령어로 / 열고 gamemode creative 입력 후 Enter (크리에이티브 복귀)
19. 크리에이티브 인벤토리: e로 열고 검색 탭에서 아이템 하나를 핫바로 가져오기, 닫기
20. 블록 고르기: 블록을 바라보고 middle_click, 그 블록이 손에 들리는지
21. 공격: 허공이나 블록에 left_click 한 번 (팔 휘두르는 모션)
22. 시점 전환: F5를 세 번 눌러 1인칭 → 3인칭 뒤 → 3인칭 앞 → 1인칭으로 돌아오는지
23. HUD 숨기기: F1로 숨기고 다시 F1로 표시
24. F3 끄기, Esc로 일시정지 메뉴 열기, 게임으로 돌아가기 버튼 클릭

== 인계 절차 (단계 24 무렵, 다음 실행에게 일을 넘길 때) ==
한 응답에 아래를 묶어서 보낸다.
 a) Esc로 게임 일시정지 (채팅창/인벤토리가 열려 있으면 먼저 닫는다)
 b) win+r, wait 1초, powershell 입력, Enter, wait 3초
 c) 열린 PowerShell 창에 아래 한 줄을 입력하고 Enter. {메모} 자리에 진행 상황을 넣는다.
    cd C:\pc-agent; uv run main.py (Get-Content prompts\minecraft_controls_test.txt -Raw -Encoding UTF8) '[이어서] {메모}'
 d) wait 5초, screenshot
- {메모} 형식 예: 릴레이 2회차. 결과 1O 2O 3O 4X(a키 반응 없음) 5O. 다음은 6번부터. 현재 서바이벌 모드.
- 메모에는 작은따옴표와 큰따옴표를 넣지 않는다.
- 릴레이 회차는 [이어서] 메모의 회차에 1을 더한다 (메모가 없으면 이번이 1회차, 넘길 메모는 2회차). 넘길 회차가 6 이상이면 인계하지 말고 그때까지의 결과만 보고하고 끝낸다.
- d)의 스크린샷에서 새 실행이 시작된 것(화면 크기 안내, [step 1/30] 같은 출력)이 보이면, 그 뒤로는 어떤 도구도 호출하지 말고 이번 실행의 결과표만 텍스트로 보고하고 끝낸다. 새 실행이 마우스와 키보드를 쓰고 있으므로 절대 건드리지 않는다.
- 새 실행이 시작되지 않았고 오류가 보이면, 남은 단계 안에서 한 번만 고쳐서 다시 실행한다.

== 최종 보고 형식 ==
항목 번호별 O/X 표와 X 항목의 실패 이유, 그리고 이번 실행에서 확인한 조작상의 특이점 (예: 시점 회전 감도, 키가 씹힌 경우)을 짧게 적는다.
