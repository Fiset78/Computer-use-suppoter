목표: 마인크래프트(Java Edition)의 기본 조작을 하나씩 실제로 해 보고, 각 조작이 이 PC 제어 환경에서 작동하는지 검증한다. 게임을 잘하는 것이 목표가 아니다. 조작마다 '입력 → 화면에서 결과 확인 → 판정 기록'을 하는 것이 목표다.

## 환경
- 마인크래프트는 창 모드로 열려 있다. 크리에이티브 모드, 평지(Superflat) 테스트 월드, 치트 허용 상태다. 처음에는 일시정지(Esc) 메뉴가 떠 있거나 다른 창이 앞에 있을 수 있다.
- 키 입력은 게임용 입력(스캔 코드)으로 전달된다. 키 배치는 Java Edition 기본값이다.

## 조작 규칙 (중요)
1. 게임 화면(커서가 숨겨진 상태)에서는 left_click, right_click, middle_click에 coordinate를 넣지 마라. coordinate를 넣으면 마우스가 움직여 시점이 돌아간다. coordinate 없이 누르면 화면 중앙 십자선이 가리키는 곳에 클릭된다.
2. coordinate를 넣은 클릭은 메뉴, 인벤토리, 채팅처럼 마우스 커서가 보이는 화면에서만 쓴다.
3. 누르고 있어야 하는 조작은 hold_key를 쓴다. 예: 1.5초 전진은 hold_key text='w' duration=1.5, 달리기는 'ctrl+w', 점프하며 전진은 'w+space'.
4. 블록을 계속 캐는 조작은 left_mouse_down → wait(초) → left_mouse_up 순서로 한다.
5. 판정은 F3 디버그 화면 값으로 한다: XYZ(위치), Facing(방향, yaw/pitch), Targeted Block(바라보는 블록). 글자가 작으면 zoom으로 확대해서 읽어라. 조작 전후 값을 비교해 판정한다.
6. 게임 화면은 계속 움직이므로 wait_for_change와 list_ui_elements는 쓰지 마라. 기다릴 때는 wait를 쓴다.
7. 한 턴에 여러 동작을 묶어 보내 턴을 아껴라. 묶음 마지막에는 screenshot 또는 F3 값을 읽기 위한 zoom을 넣는다.
8. 같은 조작이 2번 연속 실패하면 원인 추정을 기록하고 ❌로 표시한 뒤 다음 항목으로 넘어가라. 한 항목에 3턴 넘게 쓰지 마라.
9. 마우스로 시점이 돌아가지 않으면, 시점이 필요한 항목은 명령어로 대신 맞춘다: 채팅창에서 /tp @s ~ ~ ~ 0 60 (남쪽을 보고 아래로 60도). 이 경우 C 항목은 ❌로 기록한다.
10. 월드 삭제, 게임 종료(Alt+F4), 설정 변경, 서버 접속은 하지 마라.

## 턴 관리와 인계 (반드시 지킬 것)
- 이 실행은 최대 30턴(너의 응답 30번)이다. 30턴을 넘기면 강제 종료되고 진행 기록이 사라진다.
- 매 응답 첫 줄에 [턴 N/30]을 쓴다. 이번 실행의 첫 응답이 턴 1이다. 이전 실행의 턴은 세지 않는다.
- 다음 중 먼저 오는 때에 도구를 호출하지 말고 인계 보고로 응답을 끝낸다:
  (a) 모든 항목이 ✅ 또는 ❌가 되었을 때
  (b) 턴 26이 되었을 때 (남은 항목이 있어도 반드시)
- 인계 보고는 다음 실행의 너에게 주는 명령이다. 다음 실행은 화면 말고는 아무것도 기억하지 못하므로, 이어서 하는 데 필요한 사실을 빠짐없이 적어라. 아래 형식을 그대로 지키고, 블록 밖 설명은 3줄 이내로 한다.

## 시험 항목
A. 화면/메뉴
 A1 게임 화면으로 들어가기: 마인크래프트 창이 앞에 없으면 작업 표시줄 등에서 창을 클릭해 앞으로 가져온다. 일시정지 메뉴가 떠 있으면 '게임으로 돌아가기(Back to Game)'를 클릭한다. 그다음 Esc로 메뉴 열기/닫기를 확인한다.
 A2 F3: 디버그 화면 켜기 (이후 계속 켜 둔다)
 A3 F5: 시점 전환 (1인칭 → 3인칭 뒤 → 3인칭 앞 → 1인칭)
 A4 F1: HUD 숨기기 → 다시 보이기
 A5 F2: 스크린샷 (화면 아래에 저장 메시지가 뜨는지)
B. 이동 (F3의 XYZ 변화로 판정)
 B1 W 전진  B2 S 후진  B3 A 왼쪽  B4 D 오른쪽 (각각 1~2초 hold_key)
 B5 Space 점프: 'w+space'를 1초 hold_key 해서 Y가 오르내리는지, 또는 앞에 놓은 블록 위로 올라가는지
 B6 달리기: 'ctrl+w'를 같은 시간 hold_key 했을 때 W만 눌렀을 때보다 더 멀리 가는지
 B7 웅크리기: 'shift'를 hold_key 하는 동안 시야가 낮아지는지 ('shift+w'로 이동이 느려지는지)
 B8 비행(크리에이티브): key text='space' repeat=2로 비행 시작 → 'space' hold_key로 상승(Y 증가) → 'shift' hold_key로 하강 → 다시 space 두 번으로 비행 해제
C. 시점 (F3 Facing의 yaw/pitch 변화로 판정, 이 시험의 핵심 확인 사항)
 C1 mouse_move로 화면 중앙에서 오른쪽으로 200px → yaw가 바뀌는지
 C2 왼쪽  C3 위  C4 아래
 (마우스로 시점이 안 바뀌면 그 사실과 F3 값을 정확히 기록하고 규칙 9를 따른다)
D. 마우스 버튼 (십자선이 블록을 가리킨 상태에서, coordinate 없이)
 D1 left_click으로 블록 부수기 (크리에이티브는 즉시 부서짐. F3 Targeted Block이 바뀌는지)
 D2 left_mouse_down → wait 1초 → left_mouse_up으로 누르고 있기
 D3 right_click으로 블록 설치 (손에 블록이 있어야 함. 없으면 E·F 항목에서 블록을 얻은 뒤 다시)
 D4 middle_click으로 블록 집기 (그 블록이 손에 들어오는지)
E. 핫바/아이템
 E1 숫자 키 1~9로 슬롯 선택 (선택 테두리가 옮겨 가는지)
 E2 scroll(scroll_direction='down', scroll_amount=1)로 다음 슬롯, 'up'으로 이전 슬롯
 E3 F: 주 손 ↔ 보조 손 바꾸기
 E4 Q: 아이템 하나 버리기  E5 'ctrl+q': 한 묶음 버리기
F. 인벤토리 (커서가 보이므로 coordinate 클릭 사용)
 F1 E로 인벤토리 열기 → 다시 E로 닫기
 F2 크리에이티브 인벤토리 검색 탭에서 type으로 'stone' 입력 → 돌 블록을 클릭해 집고 → 핫바 칸을 클릭해 놓기
 F3 left_click에 text='shift'를 넣어 shift+클릭으로 아이템 옮기기
 F4 left_click_drag로 아이템을 여러 칸에 나누기 (가능하면)
G. 채팅/명령어
 G1 T로 채팅창 열기 → type으로 'hello from pc-agent' 입력 → Enter로 전송
 G2 '/' 키로 명령창 열기 → 'time set day' 입력 → Enter
 G3 /gamemode survival 실행 → 화면에 체력/배고픔이 보이는지 확인 → /gamemode creative로 되돌리기
 G4 한글 채팅: T → type으로 '안녕하세요' 입력 (클립보드 붙여넣기로 들어감) → Enter → 채팅에 한글이 보이는지
H. 기타
 H1 L: 발전 과제 화면 열기 → Esc로 닫기
 H2 'f3+b' 조합 키: 히트박스 표시 켜기 → 다시 'f3+b'로 끄기
