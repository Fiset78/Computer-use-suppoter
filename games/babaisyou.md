# 바바 이즈 유 (Baba Is You)
이름: 바바 이즈 유, 바바이즈유, baba is you, babaisyou

키 설정은 기본값이라고 가정한다. 화면과 다르면 화면을 믿는다.

## 이 프로그램으로 조작할 때
- 칸(격자) 단위 차례제 퍼즐이다. 키를 누를 때만 한 칸씩 움직이고, 누르지 않으면 아무것도 변하지 않는다. watch·hold_until·look은 필요 없다.
- 이동은 key로 한 번씩 누른다 (여러 칸은 repeat). hold_key로 누르고 있으면 자동 반복으로 몇 칸 갈지 알 수 없으니 쓰지 않는다.
- 마우스는 쓰지 않는다. 메뉴도 방향키 + enter로 고른다.
- 움직이기 전에 스크린샷에서 칸 좌표로 지도를 그려 둔다: 내가 조종하는 물체(YOU), 목표(WIN), 벽(STOP), 글자 블록의 위치. 화면 칸 크기를 재서 몇 칸 떨어졌는지 센다.
- 실수해도 z(되돌리기)로 몇 번이든 무를 수 있다. 막히면 r(다시 시작)보다 z가 낫다. 다시 시작도 z로 무를 수 있다.
- 키가 먹지 않으면 게임 창이 맨 앞인지 확인하고, 그래도 안 되면 입력 백엔드를 directinput으로 바꿔 본다 (--input directinput).

## 기본 조작
| 동작 | 키 |
|---|---|
| 위/아래/왼쪽/오른쪽 이동 | Up / Down / Left / Right (또는 w / s / a / d) |
| 기다리기 (한 차례 넘기기) | space |
| 되돌리기 | z (또는 BackSpace) |
| 단계 다시 시작 | r |
| 일시정지 메뉴 (단계 나가기, 설정) | Escape |
| 지도에서 단계 들어가기 / 메뉴 고르기 | Return (또는 space) |

## 규칙의 기본
- 화면에 놓인 글자 블록이 가로(왼쪽→오른쪽) 또는 세로(위→아래)로 이어져 문장이 되면 그것이 규칙이다. 예: BABA IS YOU, FLAG IS WIN, WALL IS STOP.
- 글자 블록은 늘 밀 수 있다. 밀어서 문장을 끊으면 그 규칙이 사라지고, 새로 이으면 새 규칙이 생긴다. 이것이 이 게임의 핵심이다.
- 문장 형태: 명사 IS 속성(속성을 준다), 명사 IS 명사(그 물체로 바뀐다. 예: ROCK IS FLAG면 바위가 깃발이 됨).
- 단계를 깨는 방법: YOU인 물체가 WIN인 물체와 같은 칸에 들어간다. 어떤 물체가 YOU이면서 WIN이면 바로 깬다 (예: BABA IS WIN을 만들기).
- YOU 규칙이 하나도 없으면 아무것도 움직일 수 없다. 이때는 z로 되돌린다.
- 글자 블록은 단어 칸 하나에 한 단어다. 명사 글자(BABA)와 실제 물체(바바 그림)는 다르다. 밀 수 있는 것은 글자, 규칙이 가리키는 것은 물체다.

## 자주 나오는 단어
| 단어 | 뜻 |
|---|---|
| YOU | 내가 조종한다 (여럿이면 함께 움직임) |
| WIN | YOU가 닿으면 단계 클리어 |
| STOP | 지나갈 수 없다 |
| PUSH | 밀 수 있다 (밀린 쪽이 막히면 못 민다) |
| PULL | 뒤에서 끌려온다 |
| DEFEAT | YOU가 닿으면 YOU가 없어진다 |
| SINK | 다른 물체와 겹치면 둘 다 없어진다 |
| HOT / MELT | MELT인 것이 HOT에 닿으면 없어진다 |
| OPEN / SHUT | 둘이 만나면 둘 다 없어진다 (열쇠와 문) |
| WEAK | 무엇과 겹치거나 밀려 막히면 없어진다 |
| MOVE | 차례마다 바라보는 방향으로 한 칸 간다 |
| SHIFT | 위에 있는 것을 자기 방향으로 민다 |
| FLOAT | 떠 있다. FLOAT끼리만 서로 영향을 준다 |
| TELE | 같은 TELE 물체 사이로 순간 이동 |
| AND | 여러 명사/속성을 묶는다 (BABA AND KEKE IS YOU) |
| NOT | 반대 (ROCK IS NOT PUSH) |
| HAS | 없어질 때 그 물체를 남긴다 (BOX HAS KEY) |
| ON / NEAR / FACING / LONELY | 조건 (BABA ON TILE IS WIN 등) |
| TEXT | 글자 블록 자체를 가리킨다 (TEXT IS WIN) |

## 기초 풀이 요령
1. 먼저 화면의 모든 규칙 문장을 읽고 적는다. 지금 무엇이 YOU, WIN, STOP인지 확인한다.
2. WIN 물체로 가는 길이 열려 있으면 그냥 간다. 막혀 있으면 규칙을 바꿀 방법을 찾는다.
3. 흔한 수: 막는 규칙 끊기(WALL IS STOP 밀어서 깨기), 다른 물체를 YOU로 만들기, 근처 물체를 WIN으로 만들기(X IS WIN), 나를 WIN으로 만들기(BABA IS WIN).
4. 글자를 밀 때는 미는 방향 뒤에 서야 한다. 오른쪽으로 밀려면 글자의 왼쪽 칸에서 Right를 누른다. 가장자리나 벽에 붙은 글자는 그 방향으로 밀 수 없다.
5. 글자를 한 줄로 이어 문장을 만들 때는 이미 있는 IS를 다른 방향(가로/세로)으로 함께 쓸 수 있는지 본다.
6. 규칙을 바꾼 뒤에는 스크린샷으로 실제로 바뀌었는지 확인한다 (켜진 규칙의 글자는 밝게, 꺼진 글자는 어둡게 보인다).
7. 몇 번 해 봐도 안 되면 z로 처음 상태 근처까지 되돌리고 다른 글자 조합을 생각한다.

## 지도와 진행
- 첫 단계들을 깨면 지도 화면이 나온다. 지도에서도 방향키로 움직이고 단계 위에서 Return으로 들어간다.
- 단계를 깨면 이웃한 단계가 열린다. 한 단계가 막히면 열린 다른 단계를 먼저 해도 된다.
- 단계 안에서 Escape → 메뉴에서 지도로 돌아가기를 고르면 단계를 나간다.
