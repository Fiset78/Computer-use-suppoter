# 바바 이즈 유 (Baba Is You)
이름: 바바 이즈 유, 바바이즈유, baba is you, babaisyou

키 설정은 기본값이라고 가정한다. 화면과 다르면 화면을 믿는다.

## 이 프로그램으로 조작할 때
- 칸(격자) 단위 차례제 퍼즐이다. 키를 누를 때만 한 칸씩 움직이고, 누르지 않으면 아무것도 변하지 않는다. watch·hold_until·look은 필요 없다.
- 이동은 key로 한 번씩 누른다 (여러 칸은 repeat). hold_key로 누르고 있으면 자동 반복으로 몇 칸 갈지 알 수 없으니 쓰지 않는다.
- 마우스는 쓰지 않는다. 메뉴도 방향키 + enter로 고른다.
- 퍼즐은 아래 '풀이 순서'대로 푼다. 한 칸 차이로 실패하므로 눈대중 말고 칸 수를 센다.
- 실수해도 z(되돌리기)로 몇 번이든 무를 수 있다. 막히면 r(다시 시작)보다 z가 낫다. 다시 시작도 z로 무를 수 있다.
- 키가 먹지 않으면 게임 창이 맨 앞인지 확인하고, 그래도 안 되면 입력 백엔드를 directinput으로 바꿔 본다 (--input directinput).

## 기본 조작
| 동작 | 키 |
|---|---|
| 위/아래/왼쪽/오른쪽 이동 | Up / Down / Left / Right (또는 w / s / a / d) |
| 기다리기 (한 차례 넘기기) | space |
| 되돌리기 | z (또는 BackSpace) |
| 단계 다시 시작 | r |
| 일시정지 메뉴 (단계 나가기, 설정) | Escape |
| 지도에서 단계 들어가기 / 메뉴 고르기 | Return (또는 space) |

## 규칙의 기본
- 화면에 놓인 글자 블록이 가로(왼쪽→오른쪽) 또는 세로(위→아래)로 이어져 문장이 되면 그것이 규칙이다. 예: BABA IS YOU, FLAG IS WIN, WALL IS STOP.
- 글자 블록은 늘 밀 수 있다. 밀어서 문장을 끊으면 그 규칙이 사라지고, 새로 이으면 새 규칙이 생긴다. 이것이 이 게임의 핵심이다.
- 문장 형태: 명사 IS 속성(속성을 준다), 명사 IS 명사(그 물체로 바뀐다. 예: ROCK IS FLAG면 바위가 깃발이 됨).
- 단계를 깨는 방법: YOU인 물체가 WIN인 물체와 같은 칸에 들어간다. 어떤 물체가 YOU이면서 WIN이면 바로 깬다 (예: BABA IS WIN을 만들기).
- YOU 규칙이 하나도 없으면 아무것도 움직일 수 없다. 이때는 z로 되돌린다.
- 글자 블록은 단어 칸 하나에 한 단어다. 명사 글자(BABA)와 실제 물체(바바 그림)는 다르다. 밀 수 있는 것은 글자, 규칙이 가리키는 것은 물체다.

## 자주 나오는 단어
| 단어 | 뜻 |
|---|---|
| YOU | 내가 조종한다 (여럿이면 함께 움직임) |
| WIN | YOU가 닿으면 단계 클리어 |
| STOP | 지나갈 수 없다 |
| PUSH | 밀 수 있다 (밀린 쪽이 막히면 못 민다) |
| PULL | 뒤에서 끌려온다 |
| DEFEAT | YOU가 닿으면 YOU가 없어진다 |
| SINK | 다른 물체와 겹치면 둘 다 없어진다 |
| HOT / MELT | MELT인 것이 HOT에 닿으면 없어진다 |
| OPEN / SHUT | 둘이 만나면 둘 다 없어진다 (열쇠와 문) |
| WEAK | 무엇과 겹치거나 밀려 막히면 없어진다 |
| MOVE | 차례마다 바라보는 방향으로 한 칸 간다 |
| SHIFT | 위에 있는 것을 자기 방향으로 민다 |
| FLOAT | 떠 있다. FLOAT끼리만 서로 영향을 준다 |
| TELE | 같은 TELE 물체 사이로 순간 이동 |
| AND | 여러 명사/속성을 묶는다 (BABA AND KEKE IS YOU) |
| NOT | 반대 (ROCK IS NOT PUSH) |
| HAS | 없어질 때 그 물체를 남긴다 (BOX HAS KEY) |
| ON / NEAR / FACING / LONELY | 조건 (BABA ON TILE IS WIN 등) |
| TEXT | 글자 블록 자체를 가리킨다 (TEXT IS WIN) |

## 풀이 순서 (단계마다 이 순서를 지킨다)
움직이기 전에 생각을 글로 적는다. 바로 키부터 누르면 거의 실패한다.

1. 칸 재기: 바바·글자 블록처럼 한 칸짜리 물체 두 개의 화면 좌표 차이로 칸 크기(px)를 잰다. 단계 왼쪽 위 칸을 (열 0, 행 0)으로 정한다.
2. 글자 읽기: 글자 블록은 작아서 잘못 읽기 쉽다. 단계를 시작하면 zoom으로 글자가 있는 곳을 확대해 모든 단어를 읽는다.
3. 지도 적기: 중요한 것을 (열, 행)으로 적는다. 예: 바바 (3,5) / 깃발 (12,5) / 벽 줄 열 8, 행 2~9 / 글자 WALL (1,1) IS (2,1) STOP (3,1).
4. 규칙 적기: 지금 켜진 문장을 모두 적는다 (가로·세로 둘 다). 켜진 규칙의 글자는 밝고, 문장이 안 되는 글자는 어둡다.
5. 막힌 이유 찾기: YOU가 WIN에 닿지 못하는 이유를 한 문장으로 적는다 (예: 깃발이 벽 안에 있고 WALL IS STOP이 켜져 있다 / WIN 규칙이 없다).
6. 계획: 어떤 글자를 어느 칸으로 옮겨 어떤 규칙을 만들거나 끊을지 정하고, 바바가 갈 길을 키 순서로 적는다 (예: Right×3, Up×2, Right×1).
   각 키를 누른 뒤 바바와 밀리는 글자가 어디에 있을지 미리 적는다.
7. 실행: 글자를 밀지 않는 이동은 한 번에 보내도 된다. 글자를 미는 구간은 짧게 끊어 보내고, 결과 화면이 예상한 칸과 같은지 확인한다.
8. 다르면: 왜 달랐는지 적고 z로 되돌린 뒤 다시 계획한다. 같은 시도를 되풀이하지 않는다.

## 밀기 규칙과 자주 하는 실수
- 밀기는 줄 전체가 함께 움직인다. 바바 앞에 글자가 여러 개 붙어 있으면 모두 한 칸씩 밀린다. 줄 끝이 STOP·단계 가장자리·밀 수 없는 것에 막히면 아무것도 움직이지 않고 바바도 제자리다.
- 오른쪽으로 밀려면 글자의 왼쪽 칸에 서서 Right. 글자를 원하는 칸에 놓으려면 그 글자를 몇 번, 어느 쪽에서 밀어야 하는지 먼저 센다. 방향을 바꾸려면 글자를 돌아서 반대편 칸으로 가야 한다.
- 지나가려던 길에 글자가 있으면 밀어 버린다. 켜진 규칙의 글자를 실수로 밀면 그 규칙이 꺼진다. 특히 BABA IS YOU를 깨면 아무것도 못 움직인다 (z로 되돌린다).
- 글자는 단계 가장자리 끝 줄로 밀면 다시 반대쪽으로 꺼낼 수 없다 (밀 수 있는 쪽이 사라짐). 가장자리나 구석에 글자를 붙이지 않는다.
- 같은 단어는 화면에 있는 개수만큼만 쓸 수 있다. 이미 있는 IS를 가로와 세로로 함께 쓰면 단어 하나로 두 규칙을 만들 수 있다.
- 물체 이름 글자(WALL)와 실제 물체(벽 그림)는 다르다. 벽이 STOP이어도 WALL 글자는 밀 수 있다.
- 깃발(WIN)이 STOP 물체로 둘러싸여 있으면: STOP 규칙 끊기, 나를 WIN으로 만들기(BABA IS WIN), 바로 닿을 수 있는 다른 물체를 WIN으로 만들기(X IS WIN) 중 글자 이동이 가장 적은 것을 고른다.
- 명사 IS 명사(ROCK IS BABA 등)는 모든 그 물체를 바꾼다. 바꾼 뒤 YOU가 여럿이 되거나 없어지지 않는지 생각한다.

## 배운 점 남기기
- 단계를 깨면 add_game_note로 '단계 이름: 핵심 풀이' 한 줄을 남긴다 (예: '<단계 이름>: 왼쪽 위 WALL IS STOP의 IS를 아래로 밀어 규칙을 끊고 깃발로 감'). 단계 배치는 매번 같으므로 다음에 그대로 쓸 수 있다.
- 처음에 잘못 생각했다가 알아낸 규칙(예: 어떤 단어의 실제 동작)도 한 줄로 남긴다.

## 지도와 진행
- 첫 단계들을 깨면 지도 화면이 나온다. 지도에서도 방향키로 움직이고 단계 위에서 Return으로 들어간다.
- 단계를 깨면 이웃한 단계가 열린다. 한 단계가 막히면 열린 다른 단계를 먼저 해도 된다.
- 단계 안에서 Escape → 메뉴에서 지도로 돌아가기를 고르면 단계를 나간다.
