# 발라트로 (Balatro)
이름: 발라트로, balatro

설정은 기본값이라고 가정한다. 화면과 다르면 화면을 믿는다. 게임 언어에 따라 버튼 글자가 다르니 아래 영어 이름과 화면 글자를 맞춰 본다.

## 이 프로그램으로 조작할 때
- 포커 패로 점수를 내는 차례제 카드 게임이다. 시간 제한이 없고 내가 누르기 전에는 아무것도 바뀌지 않는다. look·hold_key·hold_until은 쓰지 않는다.
- 거의 모든 조작이 마우스 왼쪽 클릭이다. 커서는 화면에 보이고 고정되지 않는다.
- 패를 내거나 버린 뒤, 상점·팩을 연 뒤에는 카드가 움직이고 점수가 올라가는 연출이 몇 초 이어진다. 연출 중에는 클릭이 먹지 않거나 엉뚱한 곳에 갈 수 있으니 wait(또는 wait_for_change)로 끝날 때까지 기다린 뒤 스크린샷을 보고 다음 행동을 한다.
- 카드 고르기는 한 번에 한 장씩 클릭한다. 고른 카드는 위로 올라간다. 고른 뒤 '패 내기'를 누르기 전에 스크린샷으로 올라간 카드가 맞는지, 화면 왼쪽에 뜬 족보 이름이 맞는지 확인한다.
- 카드·조커·쿠폰 위에 커서를 올리면(mouse_move) 설명 상자가 뜬다. 처음 보는 조커나 보스 블라인드는 설명을 읽고 정한다. 글자가 작으면 zoom으로 본다.
- 카드를 끌어서(left_click_drag) 순서를 바꿀 수 있다. 조커 순서는 점수에 영향을 준다 (아래 '점수 계산').

## 기본 조작
| 동작 | 방법 |
|---|---|
| 카드 고르기 / 고르기 취소 | 손패의 카드를 왼쪽 클릭 (최대 5장) |
| 고른 카드 모두 취소 | 오른쪽 클릭 (안 되면 고른 카드를 하나씩 다시 클릭) |
| 고른 카드로 점수 내기 | Play Hand (패 내기, 파란 버튼, 손패 아래 왼쪽) |
| 고른 카드 버리고 새로 받기 | Discard (버리기, 빨간 버튼, 손패 아래 오른쪽) |
| 손패 정렬 | 손패 아래 가운데 Rank(숫자순) / Suit(무늬순) 버튼 |
| 조커 팔기 / 소모품 쓰기 | 그 카드를 클릭 → 옆에 뜨는 Sell(팔기) / Use(사용) 버튼 |
| 블라인드 시작 / 건너뛰기 | 블라인드 고르는 화면에서 Select / Skip Blind |
| 라운드 보상 받기 | 라운드를 깬 뒤 Cash Out 버튼 |
| 상점에서 사기 | 상품 클릭 → Buy (소모품은 Buy and Use도 있음) |
| 상점 새로고침 / 상점 나가기 | Reroll / Next Round |
| 부스터 팩 | 사면 바로 열린다. 고를 카드를 클릭 → Select(또는 Use), 원하지 않으면 Skip |
| 남은 덱 보기 | 오른쪽 아래 덱 더미를 클릭 |
| 족보 레벨·점수 보기 | 왼쪽의 Run Info 버튼 |
| 설정·메뉴 (게임 속도 등) | Esc 또는 왼쪽의 Options |

## 게임 진행
- 한 판(런)은 앤티 1~8로 되어 있고, 앤티마다 스몰 블라인드 → 빅 블라인드 → 보스 블라인드 세 라운드다. 앤티 8 보스를 깨면 승리 (이후 무한 모드로 계속할 수 있음).
- 라운드마다 목표 점수(블라인드 점수)가 있다. 기본으로 패 내기 4번, 버리기 3번, 손패 8장이다. 패 내기를 다 쓰기 전에 목표 점수에 닿으면 라운드 클리어, 못 닿으면 런이 끝난다(게임 오버).
- 목표 점수 대략 (흰 스테이크 기준 스몰 블라인드): 앤티1 300, 2 800, 3 2000, 4 5000, 5 11000, 6 20000, 7 35000, 8 50000. 빅은 1.5배, 보스는 보통 2배.
- 스몰·빅 블라인드는 건너뛰고 태그(다음에 받는 보너스)를 받을 수 있다. 보스는 건너뛸 수 없다. 초반에는 돈과 조커가 필요하니 보통 건너뛰지 않는다.
- 라운드를 깨면 상점에 간다. Next Round를 누르면 다음 블라인드 고르는 화면으로 간다.

## 점수 계산
- 점수 = 칩 × 배수. 족보의 기본 칩·배수에, 실제로 점수에 쓰인 카드의 칩을 더한다.
- 카드 칩: 2~10은 숫자대로, J·Q·K는 10, A는 11. 족보에 들지 않은 카드는 칩을 주지 않는다 (예: 원 페어로 5장을 내면 페어 2장만 점수).
- 계산 순서: 낸 카드를 왼쪽부터 → 손에 남은 카드 효과 → 조커를 왼쪽부터. 그래서 +배수 조커는 왼쪽, ×배수 조커는 오른쪽에 두는 것이 좋다.

| 족보 (레벨 1) | 칩 × 배수 |
|---|---|
| 하이 카드 (High Card) | 5 × 1 |
| 원 페어 (Pair) | 10 × 2 |
| 투 페어 (Two Pair) | 20 × 2 |
| 트리플 (Three of a Kind) | 30 × 3 |
| 스트레이트 (Straight, 숫자 5장 연속) | 30 × 4 |
| 플러시 (Flush, 같은 무늬 5장) | 35 × 4 |
| 풀 하우스 (Full House) | 40 × 4 |
| 포카드 (Four of a Kind) | 60 × 7 |
| 스트레이트 플러시 | 100 × 8 |
| 파이브 카드 / 플러시 하우스 / 플러시 파이브 (같은 카드가 덱에 있어야 가능) | 120×12 / 140×14 / 160×16 |

## 카드 종류
- 조커: 기본 5칸. 계속 효과를 주는 핵심 카드. 팔면 산 값의 절반 정도를 돌려받는다.
- 행성 카드(Planet): 한 족보의 레벨을 올려 칩과 배수를 늘린다. 주로 쓰는 족보의 행성을 모은다.
- 타로 카드(Tarot): 카드의 무늬·숫자를 바꾸거나 강화(보너스, 배수, 유리 등)를 붙이거나 돈을 준다. 대상 카드를 먼저 클릭해 고른 뒤 Use를 누른다.
- 스펙트럴 카드(Spectral): 강하지만 대가가 있는 카드. 설명을 꼭 읽는다.
- 소모품(타로·행성·스펙트럴) 칸은 기본 2칸이다. 칸이 차면 더 살 수 없으니 먼저 쓴다.
- 쿠폰(Voucher): 상점에 한 앤티에 하나 나오는 영구 업그레이드.

## 돈
- 라운드 보상: 스몰 $3, 빅 $4, 보스 $5 + 남은 패 내기 1번당 $1 + 이자(가진 돈 $5마다 $1, 최대 $5).
- 이자 때문에 $25 이상을 남겨 두면 매 라운드 $5를 더 번다. 초반에는 조커에 쓰고, 조커가 갖춰지면 $25를 지키며 산다.
- Reroll은 처음 $5이고 누를 때마다 $1씩 오른다 (상점에 새로 올 때마다 처음 값으로 돌아감).

## 기초 플레이 요령
1. 한두 가지 족보(예: 플러시, 페어 계열)를 정하고 그 족보를 돕는 조커와 행성 카드를 모은다. 이것저것 섞으면 후반 점수가 모자란다.
2. 첫 상점에서는 +배수 조커(예: 그냥 Joker = +4 배수)나 +칩 조커처럼 바로 점수를 올리는 것을 산다.
3. 낼 패를 고르기 전에 목표 점수와 현재 점수를 보고, 이번 패의 예상 점수(칩 × 배수)를 계산한다. 한 번에 넘길 수 있으면 남은 패 내기 수를 아껴 돈을 더 받는다.
4. 버리기는 원하는 족보를 만들기 위해 쓴다. 쓸모없는 카드 최대 5장을 버리고 새로 받는다. 버리기는 남겨도 보상이 없으니 아낄 필요가 적다.
5. 앤티가 오를수록 목표 점수가 빠르게 커진다. 앤티 3~4 무렵에는 ×배수 조커가 있어야 한다.
6. 보스 블라인드는 고르는 화면에서 효과를 미리 보여 준다. 대비해서 조커·덱을 정리한다.

## 자주 나오는 보스 블라인드
| 보스 | 효과 |
|---|---|
| The Hook | 패를 낼 때마다 손패 2장을 무작위로 버린다 |
| The Wall | 목표 점수가 매우 크다 (4배) |
| The Psychic | 반드시 5장을 내야 한다 |
| The Needle | 패 내기가 1번뿐이다 |
| The Water | 버리기가 0번이다 |
| The Manacle | 손패 -1장 |
| The Eye / The Mouth | 같은 족보를 두 번 못 낸다 / 한 가지 족보만 낼 수 있다 |
| The Club / Goad / Head / Window | 클로버 / 스페이드 / 하트 / 다이아 카드가 점수를 내지 못한다 |
| The Plant | 그림 카드(J·Q·K)가 점수를 내지 못한다 |
| The Flint | 족보 기본 칩과 배수가 절반 |
| The Ox | 가장 많이 낸 족보를 내면 돈이 $0이 된다 |
| The Arm | 낸 족보의 레벨이 1 내려간다 |
| The House / The Wheel / The Fish / The Mark | 일부 카드가 뒤집힌 채로 들어온다 |

## 배운 점
